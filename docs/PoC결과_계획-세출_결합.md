# PoC 결과 — 계획서 × 세출예산 결합 검증

## 요약

두 데이터 소스를 실데이터로 검증했다. **계획서 파싱**과 **세출예산 API** 모두 작동하며, 둘은 "사업명·부서"라는 공통 축으로 자연스럽게 연결된다(느슨한 결합). 강한 결합(1:1 금액 매칭) 없이도 통합검색의 핵심 가치가 나온다.

---

## 1. 계획서 파싱 — 완료 ✅

「2026 전북교육 계획」 PDF(192p, 텍스트레이어 있음)에서 규칙 기반으로 **53개 세부사업**을 추출.

- 위계: `6대 분야(미래·책임·안전·자치·협력·공동체) + 청렴 → 14개 영역 → 53개 세부사업`
- 각 세부사업에 **담당부서** 100% 매핑 (예: `1-1-1 유치원 교육과정 / 유초등특수교육과`)
- 상세 페이지에서 `추진과제(▶) → 세부내용(●)`, 태그(국정과제·달라지는 정책)까지 구조화
- 산출물: `전북_세부사업_구조화.csv / .json`

## 2. 세출예산 API — 완료 ✅ (전북 실데이터 확보)

지방교육재정알리미 Open API로 **전 지역 2026 세출을 직접 수집**(전북 포함, 총 323건).

- 엔드포인트: `http://openapi.eduinfo.go.kr/openApi.do`
- requestType: **`opbdfnctByPoli`** (사업별 세출 > 기능별·정책사업별), 파라미터: `key, Type, YMQ(연도), pIndex, pSize`
- 응답 필드: `YMQ, ITEM_CD1(지역), ITEM_CD2(정책사업), AMT(금액), ITEM_CD1_SEQ(지역코드)`
- 이용허락조건: **공공누리 출처표시**(상업·비상업 이용 가능) → 내부·업무용 문제없음
- 갱신: 연 단위

## 3. 느슨한 결합 — 실제로 맞아떨어진다

계획서의 "세부사업"과 세출의 "정책사업"이 **둘 다 사업명·부서 기준**이라, 공통 축으로 나란히 검색된다. 대표 매칭 예:

| 계획서 세부사업 (담당부서) | ↔ | 세출 정책사업(항목) |
|---|---|---|
| 1-1-5 특수교육 (유초등특수교육과) | ↔ | 교수학습활동지원 > 특수교육운영/복지/여건개선 |
| 2-1 학력신장 (유초등·중등교육과) | ↔ | 교수학습활동지원 > 학력향상지원·교실수업개선 |
| 3-2-1 전북형 늘봄학교 (미래교육과) | ↔ | 교육복지 > 늘봄학교운영·방과후학교운영 |
| 3-2-3 교육비 지원 (학교안전과 등) | ↔ | 교육복지 > 교육비지원·교육급여지원 |
| 3-1-5 학생건강·보건 (문예체건강과) | ↔ | 보건급식 > 학교보건관리 |
| 2-3-2 다문화·북한배경학생 (민주시민교육과) | ↔ | 교육복지 > 다문화및북한이탈주민등자녀교육지원 |
| 4-2-2 교직원 인사행정 (교원인사과 등) | ↔ | 인적자원운용 > 교원인사관리·연수운영 |
| 2-3-4 / 평생교육 (창의인재교육과) | ↔ | 평생교육 > 평생학습운영·평생교육시설 |

→ **사용자가 "특수교육" 검색 시** 계획상 추진과제(1-1-5)와 세출상 예산항목(특수교육운영 등)이 함께 노출. 부서 필터도 양쪽 공유.
