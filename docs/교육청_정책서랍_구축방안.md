# K-교육청 정책서랍 (가칭) 구축 타당성·방안 기획서

> 참고 원본: **K-지방직 정책서랍** (klocal.solvonluchs.com) — 전국 지자체의 세출예산서·주요업무계획을 사업/부서/지역별로 검색하고 타 지역 정책사례를 비교하는 서비스.
> 본 문서는 이를 **시도교육청 도메인**으로 이식하는 방안을 정리한다.

---

## 1. 한 줄 결론

**가능하다. 오히려 원본보다 수월하다.** 대상 기관이 243개 지자체 → **16개 시도교육청**으로 줄어 데이터 수집·정제 부담이 작고, 세출예산 데이터는 **지방교육재정알리미 Open API**로 표준화되어 제공된다. 핵심 난관은 예산이 아니라 **주요업무계획(비정형 PDF/HWP) 파싱** 한 곳에 집중된다.

---

## 2. 서비스 개념 매핑

| 축 | 원본 (K-지방직) | 교육청 버전 |
|---|---|---|
| 검색 대상 기관 | 243개 지방자치단체 | **16개 시도교육청** (교육지원청 제외) |
| 예산 체계 | 지방재정 세출구조 | **교육비특별회계** 세출구조 (정책–단위–세부사업) |
| 문서 1 | 세출예산서 | 세출예산서 (교육비특별회계) |
| 문서 2 | 주요업무계획 | 교육청 주요업무계획 |
| 핵심 기능 | 사업/부서/지역별 검색 · 타지역 비교 | 동일 (사업/부서/지역별 검색 · 타 교육청 비교) |

기능 골격(검색–비교–사례열람)은 **거의 1:1로 재사용**된다. 바뀌는 것은 데이터 소스와 분류체계뿐이다.

---

## 3. 데이터 소스 (검증 완료)

### 3-1. 세출예산서 — ★ API 확보 용이

- **지방교육재정알리미 Open API** — 교육비특별회계 세입·세출, 국가시책사업, 지역교육현안사업 등을 **XML/JSON**으로 제공. 서비스의 예산 검색 기능의 1차 소스.
  - https://www.eduinfo.go.kr/portal/open/openData/openApiPage.do
- **공공데이터포털** — "한국교육학술정보원_지방교육재정알리미_예산공시" 파일데이터셋 (대량 일괄 확보용).
  - https://www.data.go.kr/data/15090206/fileData.do
- **지방재정365 / 알기쉬운재정(열린재정)** — 교육청별 예산규모·비교 지표 보강용.
  - https://www.lofin365.go.kr/portal/LF3230101.do

> 판단: 세출예산 축은 **API + 파일데이터 병행**으로 수집 난이도 낮음.

### 3-2. 주요업무계획 — △ 개별 수집 필요 (최대 공수)

- 표준 API가 **없다.** 각 시도교육청이 연초(주로 12~1월) 홈페이지·보도자료로 **PDF/HWP** 공개 (예: 경기교육청 「2026 경기교육 주요업무계획」).
- 16개 교육청 사이트를 개별 크롤링/수집 → 문서에서 **사업 단위로 구조화**하는 파싱이 필요.
- 사업명·추진과제·예산·담당부서를 추출해 예산 데이터와 **사업 키로 연결**하는 것이 핵심 부가가치.

### 3-3. (선택) 맥락 지표

- 교육통계서비스(KESS), 학교알리미 OpenAPI — 학생수·학교수 등 1인당 예산 등 파생지표 계산용.

## 4. 아키텍처 개요

```
[수집 계층]
  ├─ 예산: 지방교육재정알리미 API / 공공데이터포털 파일  ──┐
  └─ 계획: 16개 교육청 사이트 크롤링 → PDF/HWP 수집       │
                                                          ▼
[정제·구조화 계층]
  ├─ 예산 정규화: 교육비특별회계 분류체계 표준화(정책–단위–세부)
  ├─ 계획 파싱: 문서→사업 단위 추출(사업명·과제·예산·부서)
  └─ 연결: 예산사업 ↔ 계획사업 매칭(사업 키/부서 기준)
                                                          ▼
[저장 계층]  RDB(사업·기관·연도) + 전문검색 인덱스(사업명/키워드)
                                                          ▼
[API/프론트]  검색 · 필터(기관·부서·연도·금액) · 타 교육청 비교 뷰
```

## 5. 난이도 평가 (공수 배분)

| 작업 | 난이도 | 비고 |
|---|---|---|
| 세출예산 수집·정규화 | 낮음 | API/파일 표준 제공 |
| 교육비특별회계 분류체계 정리 | 중간 | 정책–단위–세부 3계층 매핑 |
| **주요업무계획 파싱·구조화** | **높음** | 비정형 PDF/HWP, 교육청별 편차 — **핵심 공수** |
| 예산↔계획 사업 매칭 | 중간 | 사업명 표기 불일치 처리 필요 |
| 검색·비교 프론트 | 낮음~중간 | 원본 구조 재사용 |

전체 프로젝트 공수의 절반 이상이 **주요업무계획 처리**에 몰린다. 여기를 얼마나 잘 푸느냐가 서비스 품질을 좌우한다.

## 6. 단계별 로드맵

**1단계 — 개념검증(PoC)**
- 2~3개 교육청(예: 경기·서울·부산)만 대상으로 예산 API 수집 + 주요업무계획 PDF 1건 파싱.
- "예산사업 검색 → 계획상 해당 사업 열람"이 실제로 연결되는지 검증.

**2단계 — 예산 축 전개**
- 16개 교육청 세출예산 전량 수집·정규화, 검색·기관간 비교 기능 완성.

**3단계 — 계획 축 전개**
- 16개 교육청 주요업무계획 수집 파이프라인 + 파싱 규칙 정비, 예산↔계획 연결.

**4단계 — 고도화**
- 연도별 추이, 1인당 예산 등 파생지표, 타 교육청 유사사례 추천.

---

## 7. 유의사항

- **회계연도·개편**: 교육비특별회계 사업분류가 연도별로 바뀔 수 있어 연도 간 비교 시 매핑 테이블 관리 필요.
- **문서 포맷 편차**: 교육청마다 주요업무계획 목차·표기 상이 → 파서를 교육청별로 튜닝하거나 문서 구조에 강건한 추출 로직 필요.
- **저작권/이용조건**: 공공데이터·공개문서 재가공이므로 각 소스의 이용약관·출처표기 확인.
- **갱신 주기**: 예산=연 1회+추경, 계획=연초 1회 → 크롤링 스케줄 단순.

---

## 8. 다음 액션 제안

가장 먼저 **1단계 PoC**를 권장한다. 실제로 다음을 실험하면 전체 타당성이 확정된다:
1. 지방교육재정알리미 API로 특정 교육청 세출예산 실제 수집 → 구조화 확인
2. 해당 교육청 주요업무계획 PDF 1건에서 사업 목록 추출 → 예산과 연결 검증

원하시면 이 PoC(실데이터 수집·파싱 실험)부터 바로 진행할 수 있다.
