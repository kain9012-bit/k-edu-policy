# 교육정책 통합검색(EduPolicy Search) — 기획·화면 명세

> 다른 도구(Google AI Studio 등)에서 이 서비스를 새로 만들 때 그대로 붙여 넣어 쓰는 명세서입니다.
> 데이터 파일(`data/*.json`)은 이미 만들어져 있고, 화면만 새로 만드는 것을 전제로 합니다.

---

## 1. 기획 의도

### 무엇이 문제인가

전국 17개 시도교육청은 해마다 수천 건의 **정책계획서**(기본계획·추진계획·운영계획·시행계획 등)를 만든다.
이 계획서들은 대부분 각 교육청 홈페이지 게시판에 공개되어 있지만, 실제로는 **찾을 수 없는 상태**에 가깝다.

- **흩어져 있다.** 17개 교육청 × 평균 10여 개 게시판. 다른 교육청 계획을 보려면 그 교육청 홈페이지에 들어가 게시판 위치를 찾아내야 한다. 게시판 이름도 `기본계획안내`, `정책자료실`, `업무공유자료실`, `통합자료실`처럼 제각각이다.
- **검색이 안 된다.** 교육청별 게시판 검색은 그 게시판 안에서만 동작한다. "다른 교육청은 늘봄학교 계획을 어떻게 세웠나"를 한 번에 확인할 방법이 없다.
- **공개된 것이 전부가 아니다.** 홈페이지에 올라오지 않은 내부결재 계획이 훨씬 많다. 이건 정보공개포털 정보목록에만 흔적이 남는다.
- **예산과 계획이 따로 논다.** 계획 문서와 그 계획에 붙은 예산이 서로 다른 시스템에 있어 "이 정책에 우리 교육청은 얼마를 쓰나"를 대조하기 어렵다.

그 결과 교육청 담당자는 계획을 세울 때마다 **맨땅에서 시작**한다. 옆 교육청이 작년에 만든 훌륭한 계획이 있어도 그게 있는 줄을 모른다.

### 이 서비스가 하는 일

공개된 자료를 한곳에 모아 **제목으로 검색되게** 만든다. 그게 전부다.

- 원본 파일을 다시 배포하지 않는다. 항상 **원문 게시글로 링크**한다.
- 자료를 새로 만들지 않는다. 이미 공개된 것을 **찾을 수 있게** 할 뿐이다.
- 어디서 언제 무엇을 가져왔는지 **전부 공개**한다. 수집이 실패한 곳도 숨기지 않는다.

### 핵심 가치

| 가치 | 의미 |
|---|---|
| **찾을 수 있게** | 17개 교육청 계획을 제목 한 번으로 가로질러 검색 |
| **원문으로 연결** | 재배포 대신 링크. 정본은 언제나 각 교육청 게시글 |
| **숨기지 않기** | 출처·수집 시각·실패 내역을 그대로 노출 |
| **공개된 것만** | 로그인·비공개 자료는 건드리지 않고, 개인정보는 수집하지 않음 |

## 2. 대상 사용자

### 1순위 — 시도교육청·교육지원청 정책 담당자 (주 사용자)

**상황:** 새 정책 기본계획을 작성해야 한다. 위에서는 "다른 교육청은 어떻게 하고 있나 보고 와라"라고 한다.

**필요한 것**
- 같은 주제로 다른 교육청이 만든 계획서를 한 번에 훑어보기
- 계획서 원문(첨부 HWP·PDF)에 바로 접근
- 우리 교육청 예산 규모가 다른 곳과 비교해 어디쯤인지 확인
- 홈페이지에 없는 계획이라도 **문서번호와 담당부서**를 알아내 직접 문의하거나 정보공개청구하기

**이 서비스가 답하는 질문**
- "늘봄학교 기본계획, 다른 교육청은 뭐라고 썼지?"
- "고교학점제 관련 계획을 세운 부서가 어디지?"
- "교육복지 예산, 우리가 17개 중 몇 번째지?"

### 2순위 — 교육정책 연구자·기자

**상황:** 특정 정책이 전국에서 어떻게 굴러가는지 비교 분석해야 한다.

**필요한 것**
- 연도별·교육청별 계획 문서의 존재 여부와 시점
- 홈페이지 공개분과 내부결재분의 격차(= 공개 수준 비교)
- 정보공개청구를 위한 정확한 문서번호·생산부서·생산일자
- 예산 시계열(2022~2026) 비교

### 3순위 — 학교 관리자·교사, 관심 있는 시민

**상황:** 우리 교육청이 이 사업을 어떻게 추진한다고 했는지 근거 문서를 확인하고 싶다.

**필요한 것**
- 전문 용어 없이도 검색되는 단순한 입구
- 원문 링크 하나

### 명시적으로 대상이 아닌 것

- 학생·학부모 대상 민원 안내 서비스가 아니다.
- 계획서 내용을 요약·해석해 주는 서비스가 아니다. **찾아서 원문으로 보내주는 것**까지가 범위다.

## 3. 데이터

정적 JSON 3개를 `fetch`로 읽는 것이 전부다. **백엔드·DB·API 서버가 없다.** GitHub Pages에 올려 동작한다.
수집은 GitHub Actions가 매일 새벽에 돌려 JSON을 갱신한다.

### 3-1. `data/documents.json` — 공개된 계획서 (게시판 수집분)

각 교육청 홈페이지 게시판을 크롤링해 모은 것. 약 **3,800건**(그중 계획서로 판별된 것 약 2,300건), 16개 교육청 179개 게시판.

```jsonc
{
  "generated_at": "2026-08-10 12:29:58",
  "count": 3820,
  "offices":        ["강원","경기", ...],        // 16
  "years":          [2005, ..., 2026],
  "departments":    ["교육복지과", ...],          // 89
  "document_types": ["기본계획","추진계획","운영계획","시행계획", ...],  // 14
  "categories":     ["늘봄·방과후","기초학력","AI·디지털교육", ...],     // 23
  "statuses":       ["정책계획서","정책참고자료","제외대상","확인필요"],
  "coverage":    { "connected": 16, "total": 16, "boards": 179, "active_offices": 16 },
  "office_stats":[ /* 교육청별 수집 통계 — 아래 참조 */ ],
  "sources":     [ /* 게시판별 출처 정보 — 아래 참조 */ ],
  "logs":        [ /* 수집 실행 로그 */ ],
  "documents":   [ /* 본체 */ ]
}
```

**`documents[]` 한 건**

```jsonc
{
  "id": "112cde182ad0a760",
  "office": "gyeongnam",            // 영문 키
  "short_name": "경남",              // 화면 표시용 짧은 이름
  "board_id": "gyeongnam-businessdata",
  "board_name": "업무공유자료실",
  "board_type": "분산형",            // 계획서전용 | 정책집중 | 분산형
  "title": "2026 전북형 늘봄학교 추진 계획",
  "department": "중등교육과",         // 없을 수 있음
  "published_date": "2026-09-01",    // 없을 수 있음
  "policy_year": 2026,
  "document_type": "추진계획",        // 없을 수 있음
  "policy_category": ["늘봄·방과후"],  // 배열, 0개일 수 있음
  "post_url": "https://...",         // 원문 게시글 (필수)
  "login_required": false,           // true면 로그인 필요 배지 표시
  "attachments": [ {"name":"...","url":"..."} ],
  "attachment_names": ["..."],
  "classification_status": "정책계획서",
  "collected_at": "2026-08-10 12:17:33"
}
```

**`classification_status` (판별 상태) — 중요**

제목을 규칙 기반으로 분류한 결과다. 화면 기본값은 **`정책계획서`만 표시**한다.

| 값 | 의미 |
|---|---|
| `정책계획서` | 계획서로 판별됨 (기본 표시 대상) |
| `정책참고자료` | 계획서는 아니지만 참고할 만한 자료 |
| `제외대상` | 계획서가 아님 (공고·입찰·인사 등) |
| `확인필요` | 판단 보류 |

**`office_stats[]` / `sources[]`** — 출처 탭에서 쓴다.

```jsonc

  "failed_boards":0, "empty_boards":0 }

// sources[]
{ "office":"전북", "board_name":"기본계획안내", "board_type":"계획서전용",
  "menu_path":"행정정보 > 정책자료 > 기본계획안내", "list_url":"https://...",
  "login_required":true, "license":"기관 공개자료(로그인 필요) · 공공누리 표기 확인",
  "robots":"허용", "count":100, "plan_count":88,
  "latest_post_date":"2026-05-26", "status":"성공", "last_collected":"2026-08-10 12:17:00" }
```

### 3-2. `data/infolist.json` — 내부결재 계획 (정보공개포털 정보목록)

정보공개포털(open.go.kr)에 등록된 **결재문서 목록**. 약 **46,000건**(2026년 1년치). 홈페이지에 공개되지 않은 계획이 여기 있다.

```jsonc
{
  "source": "정보공개포털(open.go.kr) 정보목록",
  "generated_at": "2026-08-11 03:23:13",
  "count": 46001,
  "offices":     ["경상남도교육청", ...],   // 18 — 여기는 정식 명칭
  "departments": [...],                    // 166
  "years": [2026],
  "coverage": { "from":"2026-01-01", "to":"2026-08-11", "days":223,
                "scanned":382960, "failed_days":[] },
  "documents": [ ... ]
}
```

**`documents[]` 한 건**

```jsonc
{
  "id": "il-S10CB261704749847000-20260619162946",
  "office": "경상남도교육청",
  "department": "초등교육과",
  "title": "2026. 초등(특수)교감 자격연수대상자 지명을 위한 심층면접시험 평가 위원 위촉 계획",
  "doc_no": "초등교육과-12097",     // 정보공개청구·문의에 쓰는 문서번호
  "published_date": "2026-06-19",   // 생산일자
  "has_original": false,            // 원문파일 존재 여부
  "readable": false                 // 파일 열람 가능 여부
}
```

**상세 링크 조립 규칙** — `id`는 `il-{등록번호}-{생산일시 14자리}` 형태다.

```js
function openUrl(id){
  const m = String(id||'').match(/^il-(.+)-(\d{14})$/);
  if(!m) return 'https://www.open.go.kr/othicInfo/infoList/infoList.do';
  return 'https://www.open.go.kr/othicInfo/infoList/infoListDetl.do'
       + '?prdnNstRgstNo=' + encodeURIComponent(m[1])
       + '&prdnDt=' + m[2] + '&nstSeCd=E';
}
```

**수집 범위 — 화면에 반드시 안내할 것**

- **본청 부서 문서만.** 교육지원청·도서관·연수원 등 소속·직속기관은 제외.
- 제목이 계획서 형태인 것만 남기고 `[품의]`·`[지출]`·`[협조]`·`[알림]` 같은 회계·접수 말머리는 걸러냄.
- **문서 파일은 제공하지 않는다.** 목록만 있다. 필요하면 문서번호로 부서에 문의하거나 정보공개청구.
- **담당자명은 수집하지 않는다.**

### 3-3. `data/budget.json` — 세출예산

지방교육재정알리미 Open API. 17개 시도 × 5개 연도(2022~2026) × 14개 정책사업.

```jsonc
{
  "source": "지방교육재정알리미 Open API (opbdfnctByPoli)",
  "license": "공공누리 출처표시",
  "years":   [2022,2023,2024,2025,2026],
  "regions": ["강원","경기","경남","경북","광주","대구","대전","부산","서울",
              "세종","울산","인천","전남","전북","제주","충남","충북"],   // 17
  "policy_items": ["교수학습활동지원","교육복지","교육일반","교육행정일반","기관운영",
                   "보건급식","예비비","유아및초중등교육","인건비","인적자원운용",
                   "재무활동","평생교육","학교시설여건개선","학교재정지원관리"],
  "rows": [
    { "year":2022, "region":"서울", "region_code":"B10",
      "item":"세출예산액", "amount":10588635087000,   // 단위: 원
      "is_total":true, "is_sub":false }
  ]
}
```

- `amount` 단위는 **원**. 화면에서는 `조`/`억` 단위로 축약해 보여준다 (예: `10.59조`).
- `item`에 `세출예산액`이라는 총액 행이 따로 있다. 항목 선택지는 `['세출예산액', ...policy_items]`.

## 4. 화면 구성

상단 **탭 5개**로 전환하는 단일 페이지. 페이지 이동 없이 패널만 교체한다.

```
[ 홈 ] [ 정책계획 통합검색 ] [ 내부결재 계획 검색 ] [ 세출예산 비교 ] [ 출처·수집현황 ]
```

### 탭 0. 홈 — 두 데이터셋 통합검색

첫 화면. **검색창 하나**로 시작한다.

- 큰 검색창 + `검색` 버튼. 예시 키워드 칩: `늘봄` `고교학점제` `기초학력` `인공지능` `다문화` `학교폭력` `유아교육` `진로`
- 입력하면(180ms 디바운스) **검색 결과가 좌우 2단으로** 나타난다. 입력 전에는 결과 영역을 숨긴다.
  - **왼쪽 — 공개된 계획서**: `documents.json`에서 `classification_status === '정책계획서'`이고 제목에 검색어를 포함하는 것. 최신순 5건.
  - **오른쪽 — 내부결재 계획**: `infolist.json`에서 제목에 검색어를 포함하는 것. 최신순 5건.
  - 각 단 하단에 `…에서 더 보기` 버튼 → **검색어를 물고** 해당 탭으로 이동.
- 검색어는 **제목만** 대상으로 한다(본문·첨부파일명 검색 안 함). 대소문자 무시. 일치 부분은 `<mark>`로 강조.
- 그 아래 **현황 요약 4칸**: 공개된 계획서 수 / 시도교육청 수 / 내부결재 계획 수 / 파일 열람 가능 수. 그 밑에 수집 기준일 한 줄.
- 마지막으로 **서비스 안내 카드 4개**(2×2). 각각 누르면 해당 탭으로 이동.

### 탭 1. 정책계획 통합검색

`documents.json` 전체를 다루는 본격 검색.

- 제목 검색창 + 예시 키워드 칩
- 필터: **등록 연도 / 담당부서 / 정책 분야 / 판별 상태 / 정렬**(관련도순·최신순) — 모두 `<select>`
- **교육청 선택**: 16개 칩 토글(기본 전체 선택) + `전체 선택`·`선택 해제`
- 전북 포함 여부 체크박스(전북 게시판은 로그인이 필요해 별도 표기)
- 결과 카드 한 장에: 제목(원문 링크) · 교육청/부서/유형 배지 · 게시일 · 첨부파일 목록 · 원문 게시글로 가는 버튼
- 기본값은 **판별 상태 = 정책계획서**

### 탭 2. 내부결재 계획 검색

`infolist.json`을 다룬다. 4.6만 건이라 **가상 스크롤이나 페이지네이션이 필요**하다.

- 제목 검색창
- 필터: **교육청 / 생산 연도 / 담당부서 / 정렬**(최신순·제목순)
  - 교육청을 고르면 담당부서 선택지가 그 교육청 것으로 좁혀진다
- 체크박스: `원문파일이 공개된 것만`(`has_original === true`)
- 결과 카드: 제목(정보공개포털 상세 링크) · 교육청/부서 배지 · 생산일자 · **문서번호** · 파일 열람 가능 배지
- **수집 범위 안내문을 반드시 노출**한다(3-2 참조). 문서 파일이 제공되지 않는다는 점, 본청만 수집한다는 점, 담당자명을 수집하지 않는다는 점.

### 탭 3. 세출예산 비교

`budget.json` + Chart.js 막대그래프.

- 필터: **회계연도 / 정책사업(항목) / 사업명 검색**
- **교육청 선택**: 17개 칩 토글(기본 전체) + `전체 선택`·`선택 해제`
- 그래프
  - 사업명 검색어가 **없을 때**: 선택 항목의 **교육청별 금액**을 내림차순 막대
  - 검색어가 **있을 때**: 검색과 맞는 행을 **항목별로 합산**해 막대
- 그래프 아래 **상세 표**: 교육청 / 정책사업 / 금액 / 비중(가로 막대). 상단에 `n건 · 합계 n조` 요약
- 금액 축약: 1조 이상 `1.80조`, 1억 이상 `8,000억`
- **주의:** 탭이 숨겨진 상태에서 차트를 그리면 폭이 0으로 계산돼 찌그러진다. 탭이 보이는 시점에 다시 그려야 한다.

### 탭 4. 출처·수집현황

신뢰를 만드는 탭. **잘 된 것과 안 된 것을 모두** 보여준다.

- **수집 커버리지 카드**: `16 / 16 시도교육청 연결` + 진행 막대, 계획서 수, 가장 최근 계획서 날짜, 마지막 수집 실행 시각, 자동 수집 주기
- **교육청별 수집 현황 표**: 교육청 / 계획서 / 전체 문서 / 게시판 수 / 최신 계획서 / 마지막 수집 / 상태 배지(`최신`·`지연`·`실패`)
  - 교육청 행을 누르면 그 교육청의 게시판별 내역이 펼쳐진다
- **수집 대상 게시판 전체**(179개, 접힌 상태): 교육청 / 게시판·메뉴 경로 / 수집방식 / robots / 공공누리 / 수집 건수 / 계획서 수 / 원문 링크
  - robots.txt에 제한 표기가 있는 게시판은 `⚠`로 표시

## 5. 지켜야 할 원칙

법적·윤리적 이유로 반드시 지킬 것. 화면에도 명시한다.

1. **원본 파일을 재배포하지 않는다.** 계획서 파일은 항상 해당 교육청 원문 게시글로 링크한다.
2. **개인정보를 수집·저장하지 않는다.** 담당자명·연락처는 수집 대상이 아니다.
3. **출처를 표시한다.**
   - 정책계획: 각 시도교육청 공개 게시판
   - 내부결재 계획: 정보공개포털(open.go.kr)
   - 예산: 지방교육재정알리미 Open API — **공공누리 출처표시**
4. **비공식 서비스임을 밝힌다.** 정부 공식 누리집이 아니며 공개 데이터를 모아 보여주는 서비스라는 문구를 노출한다.
5. **robots.txt·이용약관을 확인해 표기한다.** 제한 표기가 있는 게시판은 재검토 대상으로 표시한다.
6. **수집 실패를 숨기지 않는다.** 실패·지연 상태를 그대로 노출한다.

## 6. 기술 조건

- **정적 사이트.** HTML 한 파일 + `data/*.json`. 빌드 도구·프레임워크 없이 동작해야 한다(GitHub Pages 배포).
- 외부 의존성은 **Chart.js**(CDN)와 **Pretendard 웹폰트**만.
- 4.6만 건 배열을 브라우저에서 필터링하므로 **입력 디바운스(150~200ms)와 결과 렌더 제한**이 필요하다.
- 로컬 실행: `python3 -m http.server 8000`
- 반응형. 모바일에서는 2단 레이아웃을 1단으로 접는다.

## 7. 디자인 방향

**KRDS(대한민국 디지털 정부 디자인시스템)** 색상·타이포 토큰을 따른다. 다만 KRDS 컴포넌트 라이브러리(CSS/JS)를 통째로 가져다 쓰면 레이아웃이 깨지므로 **토큰만 참고해 직접 구현**하는 편이 낫다.

```css
--primary:#256ef4;  --primary-strong:#0b50d0;  --primary-darker:#083891;
--primary-surface:#ecf2fe;  --primary-border:#b1cefb;  --secondary:#1c589c;
/* 회색 계열 */
--g0:#ffffff; --g5:#f4f5f6; --g10:#e6e8ea; --g20:#cdd1d5; --g30:#b1b8be;
--g40:#8a949e; --g50:#6d7882; --g60:#58616a; --g70:#464c53; --g80:#33363d; --g90:#1e2124;
/* 상태 */
--danger:#de3412;  --success:#228738;  --warn-text:#8a5c00;  --warn-surface:#fff3db;
```

- 본문 폰트: **Pretendard**
- 모서리 반경 8px, 카드는 흰 배경 + `--g10` 테두리, 페이지 배경은 `--g5`
- 계획서 카드는 왼쪽에 `--primary` 색 세로 강조선
- 톤은 **공공기관 문서처럼 담백하게**. 장식보다 정보 밀도와 가독성 우선
- 중요: 정부 공식 서비스로 오인되지 않도록 상단 또는 하단에 비공식 서비스 안내 문구를 둔다

## 8. 만들 때 흔히 놓치는 것

실제로 겪은 문제들이다.

- **숨겨진 탭의 차트**는 폭 0으로 그려져 찌그러진다 → 탭이 보이는 순간 다시 그린다.
- **4.6만 건 렌더링**을 그대로 하면 브라우저가 멈춘다 → 화면에 그리는 건수를 제한한다.
- `published_date`, `department`, `document_type`은 **비어 있을 수 있다** → 항상 기본값 처리.
- `policy_category`는 **배열**이고 비어 있을 수 있다.
- 교육청 이름이 두 데이터셋에서 다르다 → `documents.json`은 `경남`(short_name), `infolist.json`은 `경상남도교육청`(정식 명칭). 통합 검색 시 이 차이를 감안한다.
- 예산 `region`은 **17개**인데 계획서 `offices`는 **16개**다. 두 데이터셋의 교육청 수가 다르다.
- 검색어 강조(`<mark>`) 시 정규식 특수문자를 반드시 이스케이프한다.
